 # Система управления этапами разработки

## Назначение

Приложение предназначено для управления этапами разработки программного проекта. Оно помогает отслеживать состояние этапов, контролировать сроки и понимать, какие части проекта требуют внимания.

## Целевая аудитория

Основными пользователями системы являются студенты, начинающие разработчики, руководители небольших учебных или командных проектов, а также участники проектных групп, которым нужно видеть текущее состояние разработки.

## Предметная область

Предметная область проекта связана с организацией процесса разработки программного обеспечения. Разработка обычно состоит из нескольких этапов: анализ требований, проектирование, реализация, тестирование и внедрение. Для каждого этапа важно знать срок выполнения, ответственного исполнителя, текущий статус и процент готовности.

## Основные сущности

- Проект
- Этап разработки
- Задача
- Исполнитель
- Статус этапа
- Срок выполнения

## Основные функции

- Определение текущего состояния этапа разработки.
- Проверка соблюдения срока выполнения этапа.
- Расчет оставшегося процента работы по этапу.
- Отображение краткой информации об этапе разработки.
- Формирование рекомендации по дальнейшим действиям.

## План развития

На следующих этапах планируется:

- расширить консольную программу и добавить работу с несколькими этапами;
- вынести логику проекта в отдельные функции и модули;
- реализовать основные сущности проекта в виде классов;
- разработать веб-приложение на Django;
- подключить базу данных;
- реализовать пользователей и разграничение доступа;
- добавить формы создания и изменения этапов разработки;
- разработать REST API;
- добавить автоматизированные тесты;
- контейнеризировать приложение с помощью Docker.
